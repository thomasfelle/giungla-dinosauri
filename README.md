# 🦖 Giungla dei Dinosauri

Sparatutto 3D in prima persona che gira nel browser (HTML + three.js, un solo file).

Sopravvivi a ondate di dinosauri sempre più numerosi: velociraptor, pterodattili, triceratopi e T-Rex.

## Comandi
- **WASD** muoviti · **Shift** corri · **Spazio** salta
- **Mouse** guarda · **Click** spara · **Tasto destro** mira
- **R** ricarica · **1-4** o **rotella** cambia arma
- Ogni 3 ondate: fase di costruzione (click piazza, click destro rimuove, 1-2 tipo di blocco, Invio salta)

## Come giocare
Apri `index.html` in un browser moderno (serve internet per caricare three.js da cdnjs).
La classifica Top 5 è salvata nel browser (localStorage).
